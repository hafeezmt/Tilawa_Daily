# Tilawa Daily 📖 🎙️

A modern web application built for the **Tilawa Daily** Quran recitation community (600+ members).

## Features
- **🎙️ Live Halaqah (Voice Room)**: Group recitation room with "Raise Hand" queue and admin moderation.
- **📖 Side-by-Side Digital Quran**: Full Arabic Quran with Surah, Juz, and Hizb navigation.
- **📊 Daily 5-Hizb Schedule & Khatam Tracker**: Track daily progress and community Quran completion.
- **📜 Community Rules & Announcements**: Guidelines for an organized, peaceful recitation circle.

## Tech Stack
- React / Next.js
- Tailwind CSS
- WebRTC Audio Room
- Quran Data & APIs
